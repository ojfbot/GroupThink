# CLAUDE.md — GroupThink

LLM-powered tab grouping Chrome extension. Groups browser tabs by topic and intent using Claude, displayed in a zoomable d3 treemap.

## Commands

```bash
pnpm install          # install deps
pnpm build            # inject env + compile + bundle → dist/
pnpm build:prod       # compile + bundle (no env injection)
pnpm type-check       # tsc --noEmit
pnpm lint             # biome check
pnpm lint:fix         # biome check --write
pnpm test             # vitest

# Load dist/ as unpacked extension in Chrome:
# chrome://extensions → Developer mode → Load unpacked → select dist/
# After any change: pnpm build → Chrome "reload" button on the extension card
```

## Architecture

MV3 Chrome extension built with Vite + React + @crxjs/vite-plugin.

```
src/
  manifest.json              MV3 manifest — permissions: tabs, storage, tabGroups, activeTab, debugger
  background/index.ts        Service worker. All AI calls, tab capture, caching, preemptive regrouping.
  app/
    index.tsx                Main GroupThink UI — chaos animation → treemap view
    index.html               Entry HTML for the app page
    styles.css               All component styles
  components/
    TreemapView.tsx          Zoomable d3 treemap — manages focusedGroupId + focusedChildId
    TreemapNode.tsx          Unified tile renderer (group, child-group, tab)
    TreemapBreadcrumb.tsx    Navigation breadcrumb for focused state
    TabPreview.tsx           PiP hover popover with screenshot thumbnail
    TabChaos.tsx             Loading animation — tabs fly into groups
    ChatBar.tsx              Natural language refinement input
    SpecificitySlider.tsx    1–10 granularity control
    TabCard.tsx, TabGroup.tsx, GroupGrid.tsx   Legacy grid components (unused by treemap)
  lib/
    ai.ts                    Anthropic SDK wrapper — groupTabs, sweepUncategorized, refineGrouping
    prompts.ts               System prompt + per-call prompt builders
    grouping.ts              flattenForSpecificity, shouldRePrompt, moveTab, mergeStepResults, mergeSmallGroups
    treemap-layout.ts        d3-hierarchy layout engine — computeUnifiedLayout
    treemap-colors.ts        Color palette for group tiles
    storage.ts               chrome.storage.local — config, grouping cache
    tabs.ts                  getAllTabs, focusTab, closeTab wrappers
    theme.ts                 ThemeManager — system dark/light detection
    env.ts                   Build-time injected config (gitignored)
    grid-constants.ts        Legacy grid layout constants
  options/                   Settings page — API key + model config
  popup/                     Browser action popup — opens app page
  styles/tokens.css          CSS custom properties
  types/index.ts             Shared TypeScript types
```

## Key invariants

- `ai.ts` (Anthropic SDK) is **only imported in `src/background/index.ts`** — never in app/components
- App communicates with background via `chrome.runtime.sendMessage`
- Cache-first loading: app shows cached grouping instantly on mount; background regrouping keeps cache fresh
- No silent refresh mid-navigation — avoids swapping groups while user is focused inside one
- Tab IDs are deduplicated across parent/child segments in both layout and flatten paths
- LLM prompt groups by **topic and intent**, never by website/domain
- `src/lib/env.ts` is gitignored — generated by `scripts/inject-env.js` at build time

## env.json (gitignored)

```json
{
  "ANTHROPIC_API_KEY": "sk-ant-...",
  "ANTHROPIC_MODEL": "claude-sonnet-4-20250514"
}
```

`scripts/inject-env.js` reads this at build time and writes `src/lib/env.ts`. The background service worker auto-configures on install.

## Things NOT to do

- Do not import AI SDK or `ai.ts` outside of `src/background/`
- Do not fire silent grouping refresh from the cache-hit path
- Do not create domain-based tab groups (no "YouTube", "GitHub" groups) — always topic-based
- Do not skip tab ID deduplication when building layout segments
- Do not use `alert()` or `confirm()` in production code
